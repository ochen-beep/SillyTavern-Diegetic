# Diegetic

Диегетические артефакты для SillyTavern: после ответа ИИ скрипт анализирует пост,
генерирует внутримировой HTML-объект (телефон, записка, газета, терминал…) и встраивает его
в текст сообщения между абзацами, где его рендерит JS-Slash-Runner.

Один рабочий цикл: **выбрал шаблон → нажал «Сгенерировать» → артефакт в посте.**

## Установка
1. Требуется расширение [JS-Slash-Runner](https://github.com/N0VI028/JS-Slash-Runner) ≥ 4.9.5 (проверено на 4.9.5 и 4.11.3).
2. Собери скрипт: `npm install && npm run build` → `dist/diegetic.js`.
3. Расширения → JS-Slash-Runner (酒馆助手) → библиотека скриптов → добавить глобальный скрипт,
   вставить содержимое `dist/diegetic.js`, включить.
4. В настройках раннера рекомендуется выключить подсветку frontend-кода (取消前端代码高亮).
5. Переменная чата `narlng` (язык нарратива) должна быть задана — иначе язык артефактов развалится.

## Панель (кнопка 📜 в QR-баре или ◆ справа снизу)
- **Выключатель сверху** — авторежим: пост отписался → артефакт сгенерировался сам.
- **Шаблон артефактов** — селект профиля («шаблон + источник») и кнопка
  «Сгенерировать для последнего поста» (или по ID сообщения).
- **Артефакты чата** — список с регенерацией (⟳) и удалением (✕); статус: `ok`, `fuzzy`
  (якорь найден нечётко), `orphan` (якорь не найден — артефакт записан в метаданные, но не вставлен).
- **Линза шаблона** — редактор: пустое поле = встроенная универсальная линза; можно вставить
  селективную линзу из галереи, править и сохранить; «Вернуть встроенную» откатывает.
- **Источник генерации** — на выбор: текущий API таверны, профиль подключения
  (Connection Manager, как в DS Comments) или свой OpenAI-совместимый endpoint.
- **Новый шаблон (профиль)** — создать профиль со своим источником; получает встроенную
  универсальную линзу.
- **Исключения авторежима** — фраза на строку: на постах с такой фразой авторежим молчит.
- ⟳ на артефакте в сообщении (при наведении) — быстрая регенерация.

## Один универсальный шаблон
`templates/universal.md` — встроенная линза на все случаи. Это приказ, а не вопрос: артефакт
создаётся **по каждому посту**, модель не решает «делать или нет» — только выбирает тип из
палитры (мессенджер, записка, поляроид, газета, терминал, досье, гримуар, письмо, вывеска)
по теме сцены и исполняет по рецепту; отказ в контракте запрещён. Активна «из коробки» —
ничего вставлять не надо. Селективные линзы из `templates/*.md` остаются в галерее для тех,
кто хочет фиксированный стиль. Формат ответа (`src/contract.js`) — часть контракта, не редактируется.

## Источники генерации (как в DS Comments)
Профиль = шаблон + источник. Три варианта источника:
- **Текущий API** — запрос уходит через `generateRaw` с текущим подключением таверны;
- **Профиль подключения** — выбор профиля из расширения connection-manager, запрос через
  `ConnectionManagerRequestService.sendRequest` (без пресета и instruct-форматирования);
- **Свой endpoint** — OpenAI-совместимый URL + ключ + модель (опционально).
Ключ custom-эндпоинта хранится открытым текстом в глобальных переменных раннера —
не используй критичный ключ, если другим скриптам не доверяешь.

## Что делает при старте
- Регистрирует один prompt-only regex `Diegetic prompt-strip` (вырезает ```html-блоки из промпта модели).
  Если выключить его в панели regex таверны, скрипт включит обратно при следующем старте —
  чтобы выключить стрип, отключайте сам скрипт.
- Вешает обработчики MESSAGE_RECEIVED / MESSAGE_SWIPED / MESSAGE_UPDATED / CHAT_CHANGED.

## Разработка
`npm test` — Node-тесты чистых модулей (нужен Node ≥ 21). `npm run build` — сборка
(esbuild инлайнит `templates/*.md` в бандл). `tests/harness/` — автономная страница для
проверки панели без таверны (стабы API раннера): подними любой статический сервер в этой
папке и открой index.html.
