# Diegetic

Диегетические артефакты для SillyTavern — нативное расширение: после ответа ИИ
расширение анализирует пост, генерирует внутримировой HTML-объект (телефон, записка,
газета, терминал…) и встраивает его в пост между абзацами — в sandboxed iframe,
который рендерит само расширение. JS-Slash-Runner **не требуется**.

Один рабочий цикл: **выбрал шаблон → нажал «Сгенерировать» → артефакт в посте.**

## Установка
1. Требуется SillyTavern ≥ 1.19.0 (манифестные хуки).
2. Папку расширения положить в `data/<пользователь>/extensions/` (или Extensions →
   Install extension по git-URL). Никаких скриптов в раннер вставлять не надо.
3. Переменная чата `narlng` (язык нарратива) должна быть задана — иначе язык артефактов развалится.
   Подстановка `{{getvar::narlng}}` делается нативно, на всех источниках.

## Где живут данные
- **Артефакты** — внутри сообщения: `swipe_info[i].extra.dg` (канонично, per-свайп) +
  зеркало `msg.extra.dg`. Текст поста — всегда чистая проза, артефакты не попадают
  в промпт основной модели сами собой (regex-стрип больше не нужен и удаляется миграцией).
- **Настройки** — `extensionSettings.diegetic`; **ключ custom-endpoint** — в localforage
  браузера, не в settings.json. **Исключения и флаг миграции** — `chatMetadata.dg`.
- Старые чаты с ```html-фенсами мигрируются при открытии (один проход, артефакты
  переезжают в extra с позиционной вставкой). Реестр `dg_meta` и переменные раннера
  не переносятся — артефакты переживают миграцию, список-реестр перегенерируем.

## Управление
- **Настройки** — в разделе «Расширения» таверны, секция **◆ Diegetic** (inline-drawer,
  как у других расширений): автогенерация, режим показа, место кнопки, шаблоны и источники,
  контекст генерации (персона/персонаж/лорбуки), список артефактов чата (⟳ регенерация /
  ✕ удаление; статусы `ok` / `fuzzy` / `orphan` / `stale`), фото через URIS, исключения.
- **Кнопка генерации** — на выбор («Кнопка» в настройках): **у каждого поста** (ряд
  .mes_buttons), **в квик-баре** или **плавающая** (правый нижний угол). Во время генерации
  кнопка крутится (busy-анимация). Кнопка запускает генерацию/перегенерацию для последнего
  поста ИИ; кнопка в посте — для своего поста. Повторное нажатие на крутящуюся кнопку —
  отмена: ◆ отменяет генерацию, 📷 — заливку фото; кнопка другого вида работ свой прогон
  не трогает.
- **Режимы показа** артефакта: **сразу в посте** (iframe) · **кнопка → развернуть в посте** ·
  **кнопка → во всплывающем окне** (иммерсивный лайтбокс: затемнение + артефакт по центру,
  Esc/клик по фону закрывают). В кнопка-режимах вместо артефакта — компактный ряд
  `[тип] [⧉ Copy HTML] [✕ Delete]`: тип открывает артефакт, Copy кладёт документ в буфер,
  Delete убирает артефакт из поста.
- **Контекст генерации** («Контекст генерации» в настройках): персона {{user}}, карточка
  персонажа и активированные записи World Info (dry-run скан по правилам самой таверны)
  уходят в промпт артефактов вместе с историей чата — артефакты учитывают канон.

## Если раньше пользовались скриптом в 酒馆助手
Удалите/отключите старый скрипт «Diegetic» в библиотеке скриптов JS-Slash-Runner: он
дублирует панель и генерацию, а его CSS перебивает стили расширения (при загрузке
расширение покажет предупреждение, если увидит живой старый скрипт).

## Шаблоны (профили)
Профиль = шаблон + источник генерации. Две встроенные основы (селект «Основа» в «Тексте
шаблона»): **Универсальный** и **Универсальный с фото** (тот же стиль + фотослоты
`data-dg-img`: селфи/снимки/фото к документам через URIS). Пустое поле шаблона = выбранная
основа; свой стиль = копируешь текст основы, правишь, сохраняешь в шаблон. Весь промпт
(основы и контракт) — на английском; язык текста артефакта задаёт строка «All text in
Russian» в основе. Контракт (`src/contract.js`) — только машинное ядро формата ответа
(пара `<!--DIEGETIC {json}-->` + ```html-фенс), не редактируется и всегда едет с запросом;
стиль, диегетичность и фотослоты живут в шаблоне и редактируются свободно.

## Фотослоты через UR Image Studio (мост URIS)
Если установлено UR Image Studio, модель может помечать в артефакте фотослоты —
`<div data-dg-img="trigger: описание">`. Слот всегда содержит CSS-плейсхолдер: он виден,
пока фото генерируется, и остаётся навсегда, если мост недоступен. Режимы в панели
(«Фото через URIS»): **выключено**, **по кнопке 📷** на посте (дефолт), **авто**.
Контролы на самом слоте (при наведении): ⟳ — перегенерация снимка (старая карточка
убирается из галереи URIS), ✎ — редактор промпта слота (триггер + описание; «Сохранить
и перегенерировать» сразу перезапрашивает фото). Во время генерации вместо ⟳ — ⏹:
клик отменяет заливку, слот вернётся в ожидание. Команды уходят из артефакта наружу
postMessage'ом (клики внутри sandbox-iframe до чата не доходят), а генерация — напрямую
в мост URIS с caller `sthtml`: кнопки самого URIS в посте не участвуют.

## Разработка
`npm test` — Node-тесты чистых модулей (Node ≥ 21). Сборки нет: расширение —
нативные ES-модули, хост грузит `index.js` напрямую. `PROJECT_MAP.md` — карта
архитектуры и инварианты; обновлять в конце каждой значимой задачи.
