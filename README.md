# Diegetic

Расширение для SillyTavern. После ответа персонажа добавляет в пост
небольшой интерактивный объект из мира игры: телефон, записку, газету,
терминал и т.п. Объект рисуется прямо в сообщении, между абзацами текста.

> **Это альфа-версия (0.0.1-alpha).** Всё может меняться и ломаться.

## Что умеет

- Генерировать артефакт по нажатию кнопки (последний пост или выбранный).
- Показывать артефакт сразу в посте, по кнопке в посте или во всплывающем окне.
- Копировать артефакт, сохранять его в файл .html, удалять из поста.
- Отменять удаление и перегенерацию в течение ~10 секунд (кнопка в тосте).
- Свои шаблоны стиля: берёшь готовую основу, правишь под себя, сохраняешь.
- Учитывать при генерации персону, карточку персонажа и лорбуки.
- Библиотека артефактов чата в настройках: открыть, скачать, перегенерировать
  или удалить любой; счётчик объёма; экспорт/импорт файла артефактов;
- очистка осиротевших записей; «Отделить хранилище» для форков чата.
- «Проверить подключение» — сухой запрос к источнику до первого платного поста.
- Кнопку генерации можно поставить в пост, в квик-бар или сделать плавающей
  (перетаскивается, позиция запоминается).
- Артефакты вне экрана на телефоне отключаются — экономия батареи и CPU
  (настраивается).
- Уведомления можно заглушить целиком (тумблер «без тостов»).
- Двуязычный интерфейс: русский из словаря, английские строки в коде —
  новая локаль это один JSON-файл (`src/i18n/`).

## Безопасность

- Артефакт исполняется в изолированном iframe (opaque origin) без доступа
  к таверне; сетевые запросы из артефакта закрыты CSP — работать не будут
  внешние fetch/картинки; исключение — шрифты Google Fonts.
- Ключ API хранится только в браузере (localforage), не в settings.json;
  plain-HTTP endpoint'ы вне localhost требуют явного разрешения.

## Что пока недоступно

- **Фото в артефактах через URIS (генерация изображений).** Расширение пока приватное.

## Установка

1. Нужен SillyTavern 1.19.0 или новее.
2. Поставить через «Расширения → Install extension» по ссылке на git,
   или положить папку в `data/<пользователь>/extensions/`.
   Папку `ST-HTMLblock` не переименовывать — таверна узнаёт расширение
   по имени папки.
3. Выбрать источник генерации в настройках расширения
   («Расширения → ◆ Diegetic»): профиль Connection Manager или свой
   OpenAI-совместимый endpoint.

## Настройки

Открываются в таверне: «Расширения» → секция **◆ Diegetic**. Там же
список артефактов текущего чата.

## Где живут данные

- Артефакты — в отдельном файле на сервере таверны
  (`data/<пользователь>/user/files/dg_<id чата>.json`), текст поста
  расширение не меняет никогда. Форк чата наследует этот файл; кнопка
  «Отделить хранилище» в библиотеке делает независимую копию.
- Настройки — в settings.json таверны; ключ API — только в браузере.
- При экспорте самого чата (.jsonl) файл артефактов не уезжает — используй
  «⤓ Экспорт» в библиотеке и «⤒ Импорт» на другой машине.
