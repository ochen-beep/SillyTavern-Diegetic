# Diegetic

Расширение для SillyTavern. Добавляет в пост персонажа небольшой
интерактивный объект из мира игры: телефон, записку, газету, терминал
и т.п. Объект рисуется прямо в сообщении, между абзацами текста, — его
можно потыкать, а не только посмотреть.

> **Это альфа-версия (0.0.1-alpha).** Всё может меняться и ломаться.

## Что умеет

- **Генерация.** Автоматически после каждого ответа персонажа (если
  включить автогенерацию) или по кнопке — у поста, в квик-баре или
  плавающей. Плавающую кнопку можно перетаскивать, место запоминается.
  Повторный клик по кнопке во время генерации отменяет её.
- **Показ.** Артефакт сразу в посте, свёрнутым в кнопку или в отдельном
  окне поверх чата — на выбор.
- **Действия.** Скопировать HTML, сохранить артефакт файлом .html
  (открывается в любом браузере), удалить из поста. Случайное удаление
  и перегенерацию можно отменить в течение ~10 секунд — кнопка в уведомлении.
- **Источник.** Профиль Connection Manager или свой OpenAI-совместимый
  endpoint с ключом. «Проверить подключение» делает пробный запрос до
  первого платного поста.
- **Контекст.** При генерации можно учитывать персону, карточку персонажа,
  лорбуки и историю чата — каждый пункт включается отдельно, у истории
  настраивается глубина.
- **Шаблоны стиля.** Готовые основы + свои: правь основу, сохраняй под
  своим именем, переключайся.
- **Фото в артефактах.** Если стоит UR Image Studio, артефакт может нести
  слоты для фото (селфи, документы, пейзажи). Заполняются сгенерированными
  картинками — автоматически или по кнопке 📷 на посте. У каждого фото свой
  промпт: его можно посмотреть, поправить и перегенерировать фото по одному.
  Качество (low/medium/high) — в настройках. Каждый слот — платная генерация.
- **Библиотека артефактов** в настройках: все артефакты чата списком —
  открыть, скачать, перегенерировать, удалить; видно, сколько места они
  занимают. Экспорт и импорт файла артефактов, очистка «осиротевших» записей,
  «Отделить хранилище» для форков чата.
- **Исключения.** Список фраз: посты, где фраза встретилась, авторежим
  пропускает.
- **Экономия на телефоне.** Артефакты вне экрана отключаются (настраивается).
- **Тишина.** Уведомления об успехе можно заглушить целиком.
- Интерфейс — на русском и английском.

## Безопасность

- Артефакт — это сгенерированный нейросетью код. Он запускается в
  изолированной песочнице и не имеет доступа к таверне, чатам и ключам.
- Сетевые запросы из артефакта заблокированы; единственное исключение —
  шрифты Google Fonts.
- Ключ API хранится только в браузере, на сервер таверны не уезжает.
  Endpoint по plain-HTTP вне localhost потребует явного разрешения.

## Установка

1. Нужен SillyTavern 1.19.0 или новее.
2. Поставить через «Расширения → Install extension» по ссылке на этот
   git-репозиторий, или положить папку в `data/<пользователь>/extensions/`.
   Имя папки `SillyTavern-Diegetic` не менять — таверна узнаёт расширение
   по имени папки.
3. В настройках расширения выбрать источник: профиль Connection Manager
   или свой endpoint (+ ключ).

## Ограничения

- Отредактировать HTML готового артефакта внутри таверны нельзя — можно
  перегенерировать или сохранить в файл и править снаружи.

## Где живут данные

- Артефакты — в отдельном файле на сервере таверны; текст поста расширение
  не меняет никогда. Форк чата делит этот файл с родителем — кнопка
  «Отделить хранилище» в библиотеке делает независимую копию.
- Экспорт самого чата (.jsonl) артефакты не включает — на другую машину
  их переносит «⤓ Экспорт» в библиотеке и «⤒ Импорт».
- Настройки — в настройках таверны; ключ API — только в браузере.
