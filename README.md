# Diegetic

Расширение для SillyTavern. После ответа персонажа добавляет в пост
небольшой интерактивный объект из мира игры: телефон, записку, газету,
терминал и т.п. Объект рисуется прямо в сообщении, между абзацами текста.

> **Это альфа-версия (0.0.1-alpha).** Всё может меняться и ломаться.

## Что умеет

- Генерировать артефакт по нажатию кнопки (последний пост или выбранный).
- Показывать артефакт сразу в посте, по кнопке в посте или во всплывающем окне.
- Копировать артефакт, сохранять его в файл .html, удалять из поста.
- Свои шаблоны стиля: берёшь готовую основу, правишь под себя, сохраняешь.
- Учитывать при генерации персону, карточку персонажа и лорбуки.
- Список артефактов чата в настройках: перегенерировать или удалить любой.
- Кнопку генерации можно поставить в пост, в квик-бар или сделать плавающей.

## Что пока недоступно

- **Фото в артефактах через URIS (генерация изображений).** Расширение пока приватное.

## Установка

1. Нужен SillyTavern 1.19.0 или новее.
2. Поставить через «Расширения → Install extension» по ссылке на git,
   или положить папку в `data/<пользователь>/extensions/`.
   Папку `ST-HTMLblock` не переименовывать — таверна узнаёт расширение
   по имени папки.
3. В чате должна быть задана переменная `narlng` (язык текста артефактов).

## Настройки

Открываются в таверне: «Расширения» → секция **◆ Diegetic**. Там же
список артефактов текущего чата.
