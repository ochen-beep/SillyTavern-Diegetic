# Diegetic

Диегетические артефакты для SillyTavern: после каждого ответа ИИ скрипт анализирует пост,
генерирует внутримировой HTML-объект (телефон, записка, газета, терминал…) и встраивает его
в текст сообщения между абзацами. Рендер — JS-Slash-Runner.

## Установка
1. Требуется расширение [JS-Slash-Runner](https://github.com/N0VI028/JS-Slash-Runner) ≥ 4.9.5 (проверено на 4.9.5 и 4.11.3).
2. Собери скрипт: `npm install && npm run build` → `dist/diegetic.js`.
3. Расширения → JS-Slash-Runner (酒馆助手) → библиотека скриптов → добавить глобальный скрипт,
   вставить содержимое `dist/diegetic.js`, включить.
4. В настройках раннера рекомендуется выключить подсветку frontend-кода (取消前端代码高亮).
5. Переменная чата `narlng` (язык нарратива) должна быть задана — иначе язык артефактов развалится.

## Что делает при старте
- Регистрирует один prompt-only regex `Diegetic prompt-strip` (вырезает ```html-блоки из промпта модели).
  Если выключить его в панели regex таверны, скрипт включит обратно при следующем старте —
  чтобы выключить стрип, отключайте сам скрипт.
- Вешает обработчики MESSAGE_RECEIVED / MESSAGE_SWIPED / MESSAGE_UPDATED / CHAT_CHANGED.

## Панель (кнопка ◆ справа снизу)
Вкл/выкл, профиль («шаблон+модель»), список артефактов чата (⟳ регенерация, ✕ удалить),
ручная генерация по ID сообщения, исключения (фраза на строку — авторежим молчит на таких постах).
✕ в панели снимает артефакт из списка (HTML остаётся в тексте сообщения до регенерации).
⟳ на артефакте в сообщении — быстрая регенерация.

## Профили и кастомные эндпоинты
Профиль = линза стиля + источник. Профили создаются в панели (кнопка ◆, секция «Профили»):
«Новый профиль» — имя и источник «current» (текущий API таверны) или «custom»
(OpenAI-совместимый endpoint: apiurl + ключ + модель); добавленный профиль сразу становится
активным. Линза профиля редактируется тут же в панели — вставьте содержимое .md из
`templates/` в поле «Линза активного профиля» и нажмите «Сохранить линзу».
Ключ custom-эндпоинта хранится открытым текстом в глобальных переменных раннера —
не используйте критичный ключ, если другим скриптам не доверяете.

## Линзы стилей
`templates/*.md` — исходники стилей артефактов (записка, мессенджер, поляроид, газета,
терминал, досье, гримуар) для копирования в профиль. Живая линза хранится в профиле и
правится в панели; формат ответа (`src/contract.js`) — часть контракта, не редактируется.

## Разработка
`npm test` — Node-тесты чистых модулей. `npm run build` — сборка.
Для `npm test` нужен Node ≥ 21.
